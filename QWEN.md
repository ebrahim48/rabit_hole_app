## Qwen Added Memories
- Rabbit Hole App is a Flutter game application built with Flame game engine. It features a rabbit-themed endless runner game where players control a rabbit character to avoid obstacles and collect carrots. The app includes authentication, user profiles, leaderboards, a shop system, and game mechanics. Key features include: 1) A main game screen with collision detection and scoring, 2) Authentication system with registration/login, 3) Profile management with statistics and achievements, 4) Leaderboard showing global rankings, 5) Shop with carrot packs, rabbit skins, and power-ups, 6) Settings with audio, controls, and notifications, 7) Theme management with light/dark mode. The app uses GetX for state management, GoRouter for navigation, and various UI components with custom assets.
